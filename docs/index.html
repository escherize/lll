Bring your agent.

In a second terminal, in the same project folder, add a task and create your agent’s identity.

$ lll issue create -t "Make sign-in errors clearer"
$ lll bot create bot-myproject

Paste the private prompt it prints into your coding agent. It includes the agent’s access token. You can follow its work on the board.
