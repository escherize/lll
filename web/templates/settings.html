Superuser actions. Each asks for the admin password — the credentials lll up prints in its banner — verified per action and never stored. The board token alone does not grant these.

Agent token

The web face of lll token create: a static PocketBase token that authenticates as the member. It is shown exactly once, below; tokens are stateless, so nothing can list them afterwards. Setting the member's password cuts old tokens off.

Member sign-in
